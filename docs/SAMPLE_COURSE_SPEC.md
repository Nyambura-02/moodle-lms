### 3. Detailed Course Breakdown: Junior Explorers (Ages 6–10)
**Course**: `JR-CODE-101: Creative Computing & Story Coding`

- **Pedagogical Strategy**: Visual learning, high-contrast colorful icons, audio cues, and minimal text-heavy instructions.
- **Section 1: Meet Your Digital Canvas**:
  - `page`: Interactive orientation with illustrated characters.
  - `resource`: Keyboard & mouse navigational playground guide.
- **Section 2: Building Your First Animated Character**:
  - `page`: Block coding sequence: motion, loops, and color-change events.
  - `forum`: Junior Showcase — learners share their character animations with family and classmates.
- **Section 3: The Friendly Web Explorer**:
  - `resource`: Safe Internet Rules (colorful visual comic).
  - `quiz`: Kid-friendly scenario puzzle (3 questions, unlimited attempts).

---

### 4. Detailed Course Breakdown: Middle School Innovators (Ages 11–14)
**Course**: `MS-STEM-201: STEM Robotics & Web Makers`

- **Pedagogical Strategy**: Project-oriented milestones, gamified badges, and peer collaboration.
- **Section 1: Web Foundations**:
  - `page`: HTML elements, CSS styling, and responsive layout foundations.
  - `resource`: Web Maker cheatsheet and starter templates.
- **Section 2: Sensors & Robotics Algorithms**:
  - `page`: Algorithmic thinking: condition-action pairs, sensor loops, and obstacle avoidance.
  - `assign`: Build your personal topic webpage using semantic HTML.
- **Section 3: Digital Ethics & Collaborative Science**:
  - `forum`: Discussion board on ethical tech and artificial intelligence in daily life.

---

### 5. Detailed Course Breakdown: Senior Scholars (Ages 15–18)
**Course**: `HS-CS-301: Python Data Science & Cybersecurity Foundations`

- **Pedagogical Strategy**: Career-readiness, college-level algorithmic rigor, hands-on terminal sandboxes.
- **Section 1: Python Core Foundations**:
  - `page`: Variables, data structures (lists, dictionaries), functions, and file I/O.
  - `assign`: Interactive coding exercise: analyzing real-world climate data with Python.
- **Section 2: Cybersecurity & Defense Architecture**:
  - `resource`: Cryptography primer: symmetric vs. asymmetric encryption.
  - `page`: Defensive coding and recognizing phishing attacks.
- **Section 3: Security & Ethical Hacking Lab**:
  - `quiz`: Comprehensive 15-question cybersecurity assessment.

---

### 6. Detailed Course Breakdown: Collegiate & Young Adult (Ages 18–21)
**Course**: `UNI-DEV-401: Full-Stack Web Development & Cloud Systems`

- **Pedagogical Strategy**: Industry-standard developer tooling, GitHub workflows, cloud containerization, and professional readiness.
- **Section 1: Modern Web Architectures**:
  - `page`: Client-server communication, RESTful APIs, and JWT authentication.
  - `resource`: API design guidelines and schema documentation.
- **Section 2: Cloud & Container Deployment**:
  - `page`: Docker containers, environment configuration, and microservice decoupling.
  - `assign`: Deploy a containerized web service with automated tests.
- **Section 3: Capstone Portfolio Review**:
  - `forum`: Peer-reviewed developer showcase and resume clinic.

### 7. Assessment & Question Bank Specification (`GC-SEC-101`)

The demonstration security and compliance quiz utilizes Moodle's native Question Bank and Quiz engine:

| # | Question Type | Question Title & Concept | Expected Format & Grading |
| :- | :--- | :--- | :--- |
| **Q1** | **Multiple Choice (Single Answer)** | Identifying Phishing Indicators | Identifies typosquatting in urgent emails. Auto-graded (1.0 pt). |
| **Q2** | **Multiple Choice (Multiple Answers)** | Multi-Factor Authentication Practices | Selects all valid authentication factors. Auto-graded with partial points (1.0 pt). |
| **Q3** | **True / False** | Credential Sharing Policy | "Sharing VPN credentials with a teammate is permissible if verbally approved." (False). Auto-graded (1.0 pt). |
| **Q4** | **Short Answer** | Least Privilege Definition | Enters PoLP acronym. Auto-graded with case-insensitive matching (1.0 pt). |
| **Q5** | **Essay / Extended Response** | Security Incident Escalation Procedure | Concise 3-step action plan if malware is detected. Trainer-graded with rubric (5.0 pts). |

#### Quiz Parameters:
- **Time Limit**: 20 Minutes
- **Grade to Pass**: 80% (7.2 / 9.0 points)
- **Attempts Allowed**: 2 Attempts (Highest grade recorded)
- **Review Options**: Correct answers revealed after attempt closure.

### 8. Authentication & Age-Inclusive UI Features

- **Royal Blue Design System**: Vibrant primary blue (`#2563eb`), deep navy (`#1d4ed8`), and sky cyan (`#0ea5e9`) compliant with WCAG AA accessibility contrast for both young learners and adults.
- **Google SSO**: One-click Google authentication with multi-color official icon for simplified school/university sign-in.
- **Email-Based Login**: Full support for student, parent, or educator email logins (`auth_allowemail = 1`).
- **Self-Registration**: Public account creation (`registerauth = 'email'`) with immediate dashboard access.
- **Password Recovery**: Self-service forgotten password flow (`/login/forgot_password.php`).

### 9. Kenya NITA Compliance & Trainer-Led Delivery Model

- **Regulatory Framework**: The GlobeCon Academy curriculum and instructional framework strictly adhere to the standards of the **National Industrial Training Authority (NITA)** of Kenya for technology, computing, and professional workforce skills development.
- **Trainer-Led Instruction (No Self-Paced Work)**: 
  - Every course and module is facilitated in live cohorts by certified trainers and industry mentors.
  - Interactive lab sessions, milestone reviews, and code critiques are conducted by assigned trainers (`editingteacher` role) to ensure high completion rates and vocational competence.
- **Exclusive Enrolled Student Access**:
  - The LMS portal is restricted exclusively to officially registered and tuition-paying GlobeCon students.
  - Public browsing and unsupervised self-paced completion are deactivated in accordance with NITA training guidelines.
